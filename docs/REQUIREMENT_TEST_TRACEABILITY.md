# Requirement-to-test traceability

This table is the release trace for the 0.3 implementation. Test names are
stable links from the sanitized task IDs to executable evidence. “RED” records
the original observable gap; “GREEN” records the implemented expectation.

| Task | Transition or branch | Test level and file | Preconditions and operation | Expected result | RED reason | GREEN evidence |
|---|---|---|---|---|---|---|
| BB-D00 | completion vs cancel has one winner | unit, `src/scheduler.rs`: `completion_claim_wins_later_cancellation`, `cancellation_claim_wins_later_completion` | race completion claim and cancel | exactly one outcome owns terminal | no frozen arbitration | both orders asserted; Loom terminal/cancel models pass |
| BB-C01 | cancel wakes legacy managed waits | unit/integration, `src/dam.rs` and `tests/cancel_backlog_tests.rs` | cancel interval/backoff/periodic or queued task | wait wakes; one interrupt; backlog released | waits slept until deadline and backlog could run | three virtual-clock wait tests plus six backlog tests pass |
| BB-C02 | legacy shutdown success/timeout/concurrency | integration, `tests/shutdown_report_tests.rs` | drop waiter, concurrent destroy, non-cooperative worker | shared accurate report; no false success | timeout was swallowed and handles detached | four report tests pass |
| BB-C03 | queue full vs closed and Job return | unit/integration, `src/dam.rs`, `tests/scheduler_core_tests.rs` | fill/close lane, cancel waiting submit | distinct error and original Job; no orphan | closed receiver mapped to full; no typed Job return | `closed_receiver_is_not_reported_as_queue_full`, `failed_try_submit_returns_original_job`, lane cancellation tests pass |
| BB-C04 | strict zero/empty/runtime validation | integration, `tests/strict_builder_tests.rs` | construct every legacy policy with invalid values | strict entry rejects; legacy entry unchanged | legacy silently normalized or panicked | seven strict/compatibility tests pass |

| BB-F05 | group close/generation/drop/self-shutdown | integration, `tests/scheduler_group_tests.rs` | close group, submit concurrently, drop handles, self-close, stop runtime during shutdown | isolated generation, no self-join, and final runtime-stop report | no scope lifecycle | nine group tests pass |
